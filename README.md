# Uri-Ga (우리가)

100% 투명한 가족 경제 공동체 플랫폼 v1 bootstrap.

## Workspace

- `apps/web`: Next.js dashboard
- `apps/api`: NestJS API + SSE
- `packages/db`: Prisma schema and client

## Quick Start

1. Copy env
   - `cp .env.example .env`
2. Start infra
   - `docker compose up -d`
3. Install deps
   - `pnpm install`
4. Start apps
   - `pnpm dev`
